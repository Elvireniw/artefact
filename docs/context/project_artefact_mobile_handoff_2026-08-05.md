# 1. Цель / статус проекта

**Artefact** — лендинг гончарної школи. Десктоп (14 блоків) повністю
зданий і підтверджений. Зараз йде **мобільна версія**, по одному блоку за
чат.

**За цю сесію додано/виправлено (мобіль):**
- Прибрано екран прелоадера на мобілі повністю (раніше JS встигав його
  прибрати лише ПІСЛЯ першого пофарбованого кадру — залишався видимий
  спалах).
- Блок 5 (`.gallery-mobile`) — знайдена і виправлена помилка контенту
  (карточка 1 вантажила чужий файл), поправлений відступ зверху, шов з
  блоком 6, і повністю перероблена нижня плашка карток (суцільна олива
  замість фону під кожною карткою окремо).
- Блок 7 (`.steps-mobile`) — зверстаний з нуля: заголовок, фото, карусель
  з 3 карток, ховер-свап номер/слово, курсор-підказка, прибраний нативний
  скролбар.

**Все зміни ще НЕ закомічені в git** — лежать у робочій копії.

# 2. Стек, обмеження, правила

**Стек:** статичний сайт, без збірки — `index.html` + `style.css` +
`script.js`. GSAP + ScrollTrigger + Lenis з CDN. Локальний сервер:
`node _serve.cjs` → `http://localhost:8000` (підтримує HTTP Range для
відео).

**Figma:** файл `6tA1k2sLpFm5U7cLn9p9rZ`. Усі мобільні фрейми лежать під
одним майстер-фреймом `artefact-mob` (`978:862`), 375px reference width,
на тій самій сторінці, що й десктоп (`💻 Web | Desktop`).

**Мобільний брейкпоінт:** лише один — `@media (max-width: 768px)`.
Всередині — **буквальні px**, не `--u` (fluid unit десктопу). 480px
брейкпоінт був запланований, але досі жодного разу не знадобився/не
використаний.

**Дві співіснуючі мобільні конвенції верстки** (залежно від типу вихідного
Figma-фрейму):
- Блоки 1-4 (hero/craft/clay/material) — Figma-фрейми з абсолютним
  позиціюванням → мобіль зроблений як **модифікатори на тих самих
  елементах** (`hero__title-mobile`, `craft__heading-mobile`,
  `clay__title-mobile` тощо).
- Блоки 5-7 (gallery/philosophy/steps) — Figma-фрейми на auto-layout
  (flex/gap) → мобіль зроблений як **окремий паралельний блок**
  (`.gallery-mobile`, `.philosophy-mobile`, `.steps-mobile`), десктопні
  елементи ховаються через `display:none` на брейкпоінті.

**Жорсткі правила (з CLAUDE.md, підтверджені сьогодні знову):**
- Ніякого живого CSS `blur()` — ніде. Готове розмиття, запечене в PNG
  (`mob-keramika-2.png`, `mova-clay-*.png`, футерний лого) — це ОК,
  виняток той самий, що вже був для футера.
- Ніколи не чіпляти GSAP-transform на сам `.hero` — ламає
  прелоадер→curtain стик.
- Ніякого ScrollTrigger `snap`.
- «N пікселів» на мобілі = буквальний CSS px.
- Entrance-твіни анімують до реального CSS-значення, не сліпо до
  `opacity:1`, з `clearProps` після.

**Каскадна пастка, знайдена цієї сесії:** мобільне перевизначення
властивості мусить стояти в файлі **нижче**, ніж десктопне правило з тим
самим селектором — інакше десктопне правило виграє за порядком джерела
незалежно від медіа-запиту. (Через це `.steps`'s мобільний
`height:auto;overflow:visible` спершу не спрацьовував — картки існували в
DOM з правильною геометрією, але секція обрізала їх `overflow:hidden` на
~317px.) Перевизначення `.gallery`/`.philosophy`/`.steps` тепер стоять
кожне одразу під своїм десктопним правилом.

**Тестування:** сайт на Lenis — рухати viewport треба через
`lenis.scrollTo(y, {immediate:true})` (глобальна `let lenis` у
`script.js`, доступна як голий ідентифікатор), не `window.scrollTo`.
Після синтетичного стрибка викликати `ScrollTrigger.refresh()`, інакше
entrance-анімації можуть лишитись у стані до-входу (`opacity:0`).
Емуляція `mobile` preset у браузерній панелі вимикає `:hover` (як на
реальному тачі) — щоб перевірити `(hover:hover)`-логіку, потрібен
справжній ресайжений десктопний браузер з мишею.

**Кастомний курсор:** глобальний `#cursor`, підключається на елемент
через `.js-cursor-media` + `data-cursor-label="слово"`, автоматично
вимкнений на `(hover:hover) and (pointer:fine): false` (реальний тач).

# 3. Фінальний робочий стан по блоках

## Прелоадер
`@media (max-width:768px) { .preloader { display:none; } }` — на мобілі
взагалі не малюється, ні на один кадр. Десктоп не займаний.

## Блок 5 — `.gallery-mobile` (node `978:923`)
- Картки 1-5 = `img/gallery-1.jpg` … `gallery-5.jpg` буквально по номеру
  (перевірено побайтово проти Figma-асетів). Картка 3 — досі
  плейсхолдер-заглушка (в Figma сам компонент ще `"symbol"`, не
  `"instance"` — вона не призначила реальне фото).
- Відступ зверху `.gallery-mobile`: `padding-top: 80px`.
- Шов з блоком 6: `.gallery-mobile` більше не має свого хвостового
  падінгу — весь відступ (127px, за координатами Figma) перенесений у
  `.philosophy-mobile__block--1`'s `padding-top`, тому колір шва оливковий
  (як у макеті), а не бежевий.
- Нижня плашка карток: `.gallery-mobile__bar` — суцільна оливкова смуга
  46px заввишки позаду ВСЬОГО треку (не по картці), ширина від
  `.gallery-mobile__track`'s `width:max-content` (не хардкод). Підпис
  тепер прозорий, лежить на цій смузі.
- Нативний скролбар рядка прибраний (`scrollbar-width:none` +
  `::-webkit-scrollbar{display:none}`).
- Drag-to-scroll: `initDragScrollRow('.gallery-mobile__row')` (generic-
  функція, спільна з блоком 7).

## Блок 7 — `.steps-mobile` (node `978:997`, **не** `978:1048` — та
посилання вела на блок 9)
- Заголовок — 3 картинки (`mob-keramika-1/2/3.png`), НЕ текст+CSS-blur.
  Ширини порахувані від реальних пікселів файлів (139×84, 537×184,
  447×84): найширша строка = 335px (вся колонка), інші дві — тим самим
  коефіцієнтом (87px, 279px), а не кожна на 100%.
- Фото інструментів — `img/step-art-1.jpg` (той самий файл, що на
  десктопі), квадратне, oversize-crop 150.27%/-42.42% з Figma.
- Карусель — 3 картки по 325px, `.steps-mobile__row`/`__track`, той самий
  механізм, що блок 5. Нативний скролбар прибраний.
- **Порядок карток і номери:** в Figma 2 з 3 карток мають номер-лейбл, що
  не збігається з власним текстом картки (авторська помилка при
  дублюванні компонентів). Залишений порядок карток як у Figma (1, 3, 2),
  але номер у лейблі кожної картки виправлений під її РЕАЛЬНИЙ текст:
  - картка 1: `(1)` — «від образа в уяві до ескіза» / «перш ніж глина…»
  - картка 2 (позиція): `(3)` — «додаємо душу» / «на цьому етапі…»
  - картка 3 (позиція): `(2)` — «діалог з матерією» / «саме час…»
- **Ховер номер→слово** (тільки `hover:hover`+`pointer:fine`, ніколи на
  тачі): `(1)`→«проєктування», `(3)`→«завершення», `(2)`→«втілення» —
  портовано 1-в-1 з десктопного `.step__label` механізму (crossfade
  rest/hover спанів + flex-grow спейсер, що виштовхує закриваючу дужку).
  Структура і CSS перевірені по класах (HTML↔CSS збігаються рядок в
  рядок) — саму `:hover`-взаємодію інструментами перевірити не вдалось
  (браузерна панель або емулює тач, або не дає справжнього OS-курсору);
  **потребує твоєї власної перевірки мишею**.
- **Курсор-підказка замість скролбару:** `.js-cursor-media` +
  `data-cursor-label="гортай"` на `.steps-mobile__row` — той самий
  скляний курсор-пузир, що вже є на «далі»/«стоп»/«грати».
- Entrance-анімація: заголовок → фото → картки (stagger 0.1), той самий
  беат, що блок 5.
